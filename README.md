# Yernur Visuals

Portfolio site for Yernur Visuals: photo, video, editing, reels and short commercial work.

## Commands

```bash
npm run dev
npm run build
npm run build:pages
npm test
```

The work grid currently uses public Google Drive thumbnails and preview links, so final portfolio files can be swapped by changing the Drive IDs in `app/page.tsx`.

GitHub Pages builds the static version from `.github/workflows/pages.yml` with `GITHUB_PAGES=true`, which applies the `/portfolio` base path.
